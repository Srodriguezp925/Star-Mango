# Star-Mango
La aventura del Mango Estrella es un videojuego 2D de plataformas en pixel art, donde un pequeño mango con forma de estrella emprende un viaje para encontrar a su amiga, una estrella azul de un solo ojo. En el camino enfrentará sus miedos y descubrirá que el amor propio es su mayor fortaleza.
